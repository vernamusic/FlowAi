# ⚡ FlowAI — سازنده گردش‌کار هوش مصنوعی

> گردش‌کارهای هوش مصنوعی را بسازید، اجرا کنید و عیب‌یابی کنید — تماماً داخل مرورگر.

**FlowAI** یک سازنده گردش‌کار **کاملاً فرانت‌اند** است که با **Next.js، TypeScript، Tailwind CSS، Zustand و React Flow** ساخته شده. نودها را به هم وصل کنید، متغیرها را بین آن‌ها بکشید، گراف را اجرا کنید و نتیجه را به‌صورت زنده ببینید — بدون سرور، بدون حساب کاربری و بدون پایگاه داده.

---

# ⚠️ اول این را بخوانید: FlowAI چه هست و چه نیست

FlowAI یک ابزار **محلی‌محور با کلید شخصی خودتان (BYOK)** است. شناخت محدودیت‌های آن، تفاوت بین استفادهٔ درست و غافلگیر شدن است.

### همه‌چیز در مرورگر شما اجرا می‌شود

هیچ **بک‌اندی** وجود ندارد. ویرایشگر، موتور اجرا، ذخیره‌سازی و تمام درخواست‌ها، همه در همان تبی که باز است انجام می‌شوند.

| موضوع | واقعیت |
| --- | --- |
| **محل نگهداری گردش‌کارها** | `localStorage` در همان مرورگر و همان دستگاه. پاک کردن داده‌های سایت، آن‌ها را حذف می‌کند. |
| **چه کسی می‌تواند بازشان کند** | فقط شما، در همین مرورگر. اشتراک‌گذاری، همگام‌سازی یا حساب کاربری وجود ندارد. |
| **«اجرا» یعنی چه** | صفحهٔ فعلی گراف را با JavaScript اجرا می‌کند. بستن تب، اجرا را متوقف می‌کند. |
| **زمان‌بندی** | وجود ندارد. اجرا با فشار Run انجام می‌شود، یا با تریگر بارگذاری صفحه / بازه‌ای، تا وقتی تب باز بماند. |
| **Webhook** | شبیه‌سازی‌شده. نود Webhook Trigger فقط پیلودی که خودتان می‌چسبانید را بازپخش می‌کند؛ چیزی روی آدرس عمومی گوش نمی‌دهد. |
| **هزینه** | هرچه ارائه‌دهندهٔ AI از کلید شما حساب کند. FlowAI هیچ واسطی نیست. |
| **شبکه** | فقط درخواست‌هایی که نودهای شما می‌سازند، و فقط به میزبان‌هایی که خودتان تعیین کرده‌اید. |

### کلید شخصی خودتان (BYOK)

نودهای AI مستقیماً از مرورگر و با **کلید خودتان** با ارائه‌دهنده حرف می‌زنند.

- کلیدها فقط در **`sessionStorage`** نگهداری می‌شوند. هرگز داخل گردش‌کار نوشته نمی‌شوند، اکسپورت نمی‌شوند و جز به ارائه‌دهندهٔ انتخابی شما جایی نمی‌روند.
- بستن تب کلید را پاک می‌کند. عمداً «مرا به خاطر بسپار» نداریم: هر چیزی که در `localStorage` ذخیره شود، برای هر اسکریپتی روی همان دامنه قابل خواندن است.
- **تخمین توکن و هزینه، تخمین است.** بر پایهٔ قیمت‌های عمومی و شمارش محلی توکن. مصرف واقعی، در صورت پشتیبانی ارائه‌دهنده، در گزارش اجرا ثبت می‌شود.
- چون درخواست‌ها از مرورگر شما می‌آیند، ارائه‌دهنده‌ای که مرورگر را مسدود کند (CORS) یا راز سمت سرور بخواهد کار نمی‌کند.

# ✨ قابلیت‌ها

### 🎨 سازندهٔ بصری گردش‌کار

- نود را از کتابخانه بکشید، روی آن **کلیک کنید** تا وسط صفحه اضافه شود، یا از پالت فرمان آن را اضافه کنید
- اتصال نودها با کشیدن بین دستگیره‌ها، و حذف اتصال با کلیک روی آن و زدن Delete
- شاخه‌های True / False برای Condition و شاخه‌های Body / After برای Loop
- Undo / Redo، تکثیر، حذف، مینی‌مپ، بزرگ‌نمایی و جابه‌جایی
- چسبیدن به شبکه، و نگه‌داشتن **Space** برای جابه‌جایی صفحه از هر نقطه، حتی روی نود
- پالت فرمان (**Ctrl/⌘ + K**) برای یافتن گردش‌کار، افزودن نود یا اجرای یک کنش
- کنترل کامل با صفحه‌کلید، همراه با راهنمای میان‌برها (`?`)

### 📊 اجراها و هزینهٔ آن‌ها

- هر اجرا در مرورگر نگه‌داری می‌شود، **۲۰ اجرای آخر**
- صفحهٔ `/executions` آن‌ها را با وضعیت، مدت، توکن و هزینه فهرست می‌کند
- صفحهٔ هر اجرا: لاگ‌ها، ورودی و خروجی هر نود، و آنچه هر نود AI خرج کرده
- توکن و هزینه به تفکیک گردش‌کار، و به تفکیک روز برای ۱۴ روز گذشته
- هزینه‌های تخمینی با `*` مشخص می‌شوند، و مجموعی که ترکیبی از اجراهای قیمت‌دار و بدون قیمت است، همین را می‌گوید و وانمود نمی‌کند بقیه رایگان بوده‌اند

### 🛡 وقتی یک نود شکست بخورد

هر نود به‌جز تریگرها سه تنظیم دارد:

- **تلاش دوباره** — ۱ تا ۵ بار بیشتر، با فاصله بین تلاش‌ها. یک API ناپایدار فرصت دوم می‌گیرد به‌جای اینکه کل اجرا را خراب کند
- **مهلت** — سقف زمانی برای هر تلاش، تا تماسی که گیر می‌کند نود را خراب کند نه کل جلسه را
- **ادامه با وجود خطا** — اجرا در بقیهٔ گراف ادامه پیدا می‌کند. نود همچنان خطا نشان می‌دهد و خطا به‌صورت `error` به پایین‌دست می‌رود

### 🧩 شانزده نوع نود

| دسته | نودها |
| --- | --- |
| تریگرها | Manual Trigger، Webhook Trigger (شبیه‌سازی‌شده)، Page Load Trigger، Interval Trigger |
| هوش مصنوعی | AI Prompt |
| منطق | Condition، Switch، Merge، Math، Text، Set Variable، JSON Parser، Loop |
| عملیات | HTTP Request، Delay، Output |

**Math** یک عبارت حسابی می‌گیرد — `+ - * / % ^`، پرانتز، و
`abs ceil floor max min pow round sqrt` — و هرگز آن را به‌عنوان کد اجرا نمی‌کند.
**Switch** به اولین حالت منطبق می‌رود، با یک شاخهٔ پیش‌فرض.
**Merge** چند شاخه را دوباره در یک مقدار جمع می‌کند.

### ⏱ تریگرهایی که خودشان اجرا می‌شوند

Page Load و Interval بدون فشردن Run گردش‌کار را شروع می‌کنند. هر دو فقط
**تا وقتی ادیتور باز است** اجرا می‌شوند: FlowAI سروری ندارد، پس بستن تب یعنی
هیچ اجرایی. اجرای زمان‌بندی‌شده به‌صورت پیش‌فرض dry run است، چون تایمری که تا
همیشه تکرار شود نباید بی‌سروصدا خرج ایجاد کند.

### 🤖 هوش مصنوعی واقعاً زنده

- هر ارائه‌دهندهٔ **سازگار با OpenAI**: OpenAI، Ollama یا سرور خودتان
- خروجی **stream** که هم‌زمان با نوشتن مدل نمایش داده می‌شود
- قالب پاسخ: **متن**، **JSON** یا **structured output** با اسکیمای دلخواه
- **اجرای آزمایشی** داخل inspector، بدون نیاز به اجرای کل گراف
- تخمین توکن و هزینه پیش از اجرا، مصرف واقعی پس از اجرا
- قالب‌های prompt، دستورهای سیستمی آماده و اسکیماهای پیش‌فرض

### 🔗 متغیرهایی که حقیقت را می‌گویند

- هر نود فقط متغیرهای نودهایی را می‌بیند که **واقعاً به آن بالا وصل‌اند**
- `{{node.items[0].title}}` ایندکس آرایه، `{{node.meta["order-id"]}}` کلید براکتی، `{{node.customer?.email}}` دسترسی اختیاری، `{{node.total ?? "n/a"}}` مقدار پیش‌فرض
- پنل **Variables** همهٔ مقادیر گردش‌کار را با نتیجهٔ آخرین اجرا نشان می‌دهد
- ارجاع‌های خراب **پیش از اجرا** گزارش می‌شوند، همراه با نودی که باید اصلاح شود

### ⚙️ موتور اجرا

- اجرای توپولوژیک با رعایت ترتیب وابستگی‌ها
- شاخه‌بندی، رد شدن و جداسازی خطا
- Loop که زیردرخت را برای هر آیتم تکرار می‌کند، با گزارش جداگانه برای هر تکرار
- لغو فوری اجرا، حتی وسط Delay
- Dry run که هرگز شبکه را لمس نمی‌کند
- تاریخچهٔ اجرا (۲۰ اجرای اخیر) با قابلیت کپی ورودی و خروجی

### 🧪 تست‌پذیر

- **۱۵۹ تست واحد و کامپوننت** (Vitest)
- **۳۲ تست مرورگر** (Playwright) برای ساخت، ذخیره، ایمپورت، اکسپورت، بازنشانی و داده‌های خراب
- اجرای همه با `npm run test:all`

# 🔒 حریم خصوصی

- گردش‌کارها و تاریخچهٔ اجرا: `localStorage`
- کلید ارائه‌دهندهٔ AI: `sessionStorage`، جدا برای هر ارائه‌دهنده
- هیچ داده‌ای به هیچ سرویس FlowAI ارسال نمی‌شود، چون چنین سرویسی وجود ندارد
- درخواست‌ها فقط وقتی از مرورگر خارج می‌شوند که نودی اجرا شود و میزبانی را که خودتان تعیین کرده‌اید صدا بزند
